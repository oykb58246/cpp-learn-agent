# CppPilot 助教背景档案设计

## 目标

将 CppPilot 从知识闯关式学习产品调整为编程助教。应用不判定用户是否真正掌握知识，不安排测验，也不以 XP、等级、勋章或解锁作为主要体验。它保存用户自述的 C++ 背景，并在解释代码、报错和新概念时据此选择合适的讲解深度。

## 首次启动

首次进入完成环境引导后，显示“告诉助教你的 C++ 背景”流程：

1. 用户选择“零基础”或“学过一点”。
2. 零基础直接保存空的已学节点集合，进入首页。
3. 学过一点时按现有知识树节点展示可勾选项。用户只标记“我学过”和“希望重点解释”的节点，不需要填写每一个节点。
4. 任一节点的前置节点均未标记为学过时，后置节点在知识树中推导为“尚未接触”。
5. 学习档案始终可在知识树页面重新编辑；首次咨询不要求测试或百分比。

## 知识树

页面名称保留“知识树”，但副标题改为“让助教了解你的 C++ 背景”。原有节点与前置关系保留，节点只呈现以下用户可理解状态：

- `学过`：用户自述，可被助教直接作为解释前提。
- `希望重点解释`：用户希望助教放慢拆解、补足细节的概念。
- `尚未接触`：由前置关系和用户未标记状态推导；助教可介绍，但不能假定用户已知。

知识树按基础到进阶的学习路径展示，顶部固定显示当前背景摘要、已标记节点数、当前重点节点和“编辑我的背景”操作。它不显示锁定、验证、等级、复习、进度百分比或“开始学习”按钮。

## 助教解释上下文

原 `KnowledgeGate` 不再阻断 Agent 或将请求改写为“先学习前置知识”。它转换为解释上下文：

- 请求涉及已学节点时，Agent 可以直接以这些概念为类比或前提。
- 请求涉及重点解释节点时，Agent 应拆分步骤、提供更小的例子并解释术语。
- 请求涉及尚未接触节点时，Agent 必须先给出足以理解当前问题的简短引入，再继续分析；不拒绝回答。

助教使用档案作为解释偏好，不能将用户自述写成“已验证”或“已掌握”的系统结论。

## 首页

首页改为“今天怎么继续”的助教入口，只回答：

1. 用户此刻能做什么：打开最近项目继续编码，或向助教描述问题。
2. 助教会如何帮助：解释代码、分析报错、给出下一步建议，不替用户完成学习或代码。
3. 当前项目从哪里继续：最近项目、最近问题或当前建议。

移除 XP、等级、勋章、成长阶段、待复习和闯关任务。工具链未准备好时保留清晰的环境修复入口。

## 助教记录

侧边栏中的“练习”“报告”“Agent 记录”合并为“助教记录”。该页面按用户可理解的内容呈现：

- 历史报错与解决过程。
- 助教解释过的代码或概念。
- 助教给出的后续建议。

每条记录优先展示问题、结论、用户下一步和关联项目；内部执行计划、审批和工具调用放入可展开的“技术详情”。既有运行记录转换为助教记录摘要，保留可追溯性而不丢弃历史。

## 数据与兼容

- 保留 `knowledge_nodes`、项目、错误本和 Agent 运行记录数据。
- 用背景档案状态替代用户面对的 `locked`、`verified`、`review` 语义。迁移时旧的 `learning`、`self-claimed`、`verified` 归入“学过”；有待处理错误关联的节点归入“希望重点解释”。
- 废弃学习证据、XP、成就和复习 UI 的读取与写入路径，但不删除历史数据表。
- 将已有 Agent run 映射为用户可读摘要；缺少用户回答时仍显示运行意图和完成状态。

## 错误处理与测试

- 档案保存失败时不覆盖当前本地展示，显示可重试错误。
- 缺少学习档案时，Agent 以零基础上下文解释，并在首页提示完成背景咨询。
- 单元测试覆盖状态推导、旧状态迁移、解释策略和记录摘要。
- 桌面端组件测试覆盖首次咨询、知识树编辑、首页首要操作、助教记录筛选与详情展开。
- Playwright 验证零基础与“学过一点”两条首次流程、知识树状态呈现和助教记录合并后的导航。

# CppPilot 新手引导与 Agent 助教体验设计

## 目标

为第一次使用 CppPilot 的 C++ 新手提供一条清晰、低打扰、可完成的试用路径。用户应能在五分钟内知道产品的主要区域，向 Agent 助教提交第一个真实问题，理解助教回答与处理记录的位置，并知道如何在代码工作区中继续使用助教。

该功能不替代现有环境初始化。环境初始化负责检测工具链和授权工作区；本设计负责解释产品并帮助用户完成首次核心体验。

## 成功标准

- 完成环境初始化和学习背景填写后，首次进入首页能看到明确的“新手体验”入口。
- 用户不必配置在线模型，也能通过离线 Agent 完成一次真实问答。
- 完整引导覆盖首页功能概览、Agent 首次提问、回答与处理记录、工作区 Agent 入口。
- 用户可以跳过、稍后继续、完成后重看；状态跨重启保留。
- 引导不会阻断正常导航，也不会与环境初始化或学习背景弹窗同时出现。
- 在 1440x900 和 1024x720 窗口中，引导内容无溢出、遮挡或不可点击控件。

## 体验结构

### 1. 首页新手体验卡

首页在新手引导未完成时显示一个独立的快速开始区域，包含当前进度和三个可理解的任务：

1. 认识 CppPilot 的主要区域。
2. 向 Agent 助教提出第一个问题。
3. 在代码工作区中继续使用助教。

首次进入首页仅显示一次轻量欢迎提示，提示用户可以立即开始或稍后处理。完整引导由用户主动开始，避免连续经历环境初始化、背景填写和强制导览。

卡片在引导完成后收起。侧边活动栏提供帮助按钮，允许随时重新打开新手体验；重看不清除原完成记录。

### 2. 跨页面情境引导

引导使用应用级组件渲染遮罩、目标高亮和说明面板。步骤由一个集中定义的步骤表驱动，每个步骤包含路由、目标选择器、标题、说明、位置和前进条件。

引导步骤如下：

1. **首页与功能区**：说明首页、工作区、知识树和助教记录分别解决什么问题。
2. **助教入口**：自动进入助教记录页并聚焦输入区。
3. **首次真实提问**：提供“解释这段循环代码”等示例问题。用户可以一键填入，也可以编辑后发送。
4. **查看助教结果**：等待 Agent 运行完成后，聚焦回答、下一步建议和可展开的处理过程。
5. **结合代码继续**：有项目时进入工作区并定位 Agent 按钮；无项目时回到首页的新建项目入口，并说明创建项目后可选择代码让助教解释或排错。
6. **完成**：显示已经掌握的操作，并提供“留在当前页”与“返回首页”两个明确动作。

路由切换后，组件等待目标元素出现并重新测量。目标不存在时不显示空白遮罩，而是使用居中说明面板提供继续或跳过该步的操作。

### 3. Agent 首次体验

AgentComposer 增加可选的引导态能力：外部可传入建议问题，并在用户点击时填入输入框。正常使用时组件行为不变。

首个建议使用“解释代码”模式，并包含一个最小循环代码片段。该请求即使没有项目上下文，也会由现有离线工作流返回针对循环的解释，因此不依赖 API Key、网络、编译器或项目。

发送后，引导不自动伪造成功。它监听 Agent store 的真实运行状态：

- 运行中显示“助教正在阅读问题”。
- 完成后允许进入结果说明步骤。
- 失败时保留当前页面，展示现有错误信息，并提供重试、跳过该步或退出引导。
- 需要审批时让用户先处理真实审批卡，再继续。

### 4. 引导状态

在 `AppSettings` 中增加以下字段，并通过现有 JSON 设置存储持久化，不引入数据库表：

- `productTourStatus`: `pending | in-progress | completed | dismissed`
- `productTourStep`: 当前步骤索引
- `productTourWelcomeSeen`: 是否已经展示轻量欢迎提示

旧数据缺少字段时迁移为 `pending`、步骤 `0`、欢迎提示未展示。重新体验使用组件内的 replay 标记，不把已完成状态改回 pending。

状态变化规则：

- 开始引导时写入 `in-progress` 和当前步骤。
- 每次完成步骤后写入新步骤，应用重启后从该步骤恢复。
- “稍后继续”保留 `in-progress`，只关闭当前浮层。
- “不再提示”写入 `dismissed`。
- 完成全部步骤写入 `completed`。
- 从帮助按钮重看时不覆盖 `completed` 或 `dismissed`。

## 组件与职责

### `ProductTour.vue`

- 读取步骤定义和引导 store。
- 负责路由跳转、目标定位、遮罩裁切、键盘焦点和窗口变化后的重新测量。
- 暴露开始、暂停、跳过和重看动作。
- 不直接执行 Agent 请求或创建项目。

### `BeginnerQuickStart.vue`

- 在首页展示进度、任务和主操作。
- 根据状态显示“开始体验”“继续体验”或隐藏。
- 将实际引导启动交给引导 store。

### `stores/product-tour.ts`

- 保存本次会话的打开状态、重看状态和当前步骤。
- 通过 app store 持久化产品引导设置。
- 根据 Agent 和工作区状态判断步骤是否满足前进条件。

### 现有页面改动

- `App.vue`：挂载应用级引导组件，在活动栏增加帮助入口，并协调背景填写完成后的欢迎提示。
- `HomeView.vue`：挂载新手体验卡并给关键入口添加稳定的 `data-tour` 标记。
- `RunsView.vue`：给输入区和结果区添加目标标记，向 AgentComposer 传递引导建议问题。
- `WorkspaceView.vue`：给工作区 Agent 按钮和面板添加目标标记。
- `AgentComposer.vue`：支持建议问题和填入事件，不改变提交协议。

## 可访问性与交互

- 引导面板使用 `role="dialog"` 和可理解的标题关联。
- 打开时焦点进入引导面板，关闭时回到启动控件。
- `Escape` 执行“稍后继续”，不将引导标记为完成。
- 遮罩不允许点击被遮挡区域；被聚焦目标仅在步骤需要真实操作时可交互。
- 前进、返回、稍后继续和关闭均使用文字明确的按钮；侧栏帮助入口使用 Lucide `CircleHelp` 图标和 tooltip。
- 说明面板使用固定最大宽度和视口边界约束，小窗口下切换为底部面板。
- 尊重 `prefers-reduced-motion`，减少遮罩和面板位移动画。

## 错误与边界处理

- 环境初始化未完成时仍可体验无项目的离线解释问题，但工作区步骤改为说明如何返回环境向导。
- 学习背景尚未保存时不启动产品引导，先完成现有必填背景对话框。
- 路由目标在超时后仍不存在时显示居中回退说明，用户可以重试定位或跳过该步。
- Agent 运行已经存在时禁用再次发送，并说明需要等待或停止当前任务。
- 页面刷新或应用重启后，从持久化步骤恢复，但不自动弹出遮罩；首页卡片显示“继续体验”。
- 引导状态写入失败时关闭引导并复用全局错误提示，避免出现看似完成但未保存的状态。

## 测试策略

### 单元测试

- 数据库设置默认值和旧数据迁移。
- 引导 store 的开始、前进、暂停、跳过、完成和重看状态转换。
- AgentComposer 建议问题填入，不会在未确认时自动发送。
- 目标缺失、Agent 失败和无项目分支的步骤解析。

### 端到端测试

- 新用户完成环境流程和背景填写后看见新手体验入口。
- 开始引导后可以跨首页和助教记录页移动。
- 点击示例问题后提交真实离线 Agent 请求，并在完成后看见回答与下一步建议。
- 退出后首页显示继续入口；完成后入口收起；帮助按钮可以重看。
- 在 1440x900 和 1024x720 下检查无横向溢出，并保存关键步骤截图。

## 非目标

- 不重新设计环境初始化向导。
- 不自动创建或修改用户项目。
- 不实现课程、成绩、测验或学习进度系统。
- 不引入第三方导览库。
- 不自动替用户发送 Agent 问题或批准高风险操作。

# H2 接收清单

## 自动验证

- [ ] Windows 10/11、Node.js 22+、pnpm 10.24.0。
- [ ] 执行 `pnpm install --frozen-lockfile`。
- [ ] 执行 `pnpm typecheck`，全部通过。
- [ ] 执行 `pnpm test`，33 个测试通过。
- [ ] 执行 `pnpm build`，Main、Preload、Renderer 和 Monaco Worker 构建成功。
- [ ] 执行 `pnpm test:e2e`，Electron E2E 通过。
- [ ] 测试结束后执行 `pnpm native:electron`，再启动开发环境。

## 编辑与工程

- [ ] 全新用户数据首次启动自动进入环境初始化向导。
- [ ] 向导可完成环境检测、推荐工具链验证绑定、工作区选择/信任和完成确认。
- [ ] 缺失工具只打开预设官方页面，不接受任意 URL，也不静默安装。
- [ ] 选择“稍后配置”后可以进入首页，并能从设置页重新打开向导。
- [ ] 跳过前明确提示找回路径，跳过后首页显示可关闭的环境提醒。
- [ ] WinGet 可用时可在用户确认后打开可见安装终端；不接受任意软件包或命令。
- [ ] WinGet 任务结束后更新成功/失败状态，成功时自动重新检测环境。
- [ ] 1024×720 下向导无横向溢出或按钮遮挡。
- [ ] Monaco 可编辑、保存、多标签切换，外部修改冲突进入 Diff。
- [ ] 单文件编译运行可选择 C++17、C++20、C++23。
- [ ] 语法错误进入问题面板并定位到编辑器。
- [ ] 死循环可停止或在超时后回收进程。
- [ ] CMake 项目可工程构建并生成 `compile_commands.json`。
- [ ] CTest 可执行并显示通过/失败数量。
- [ ] VS Code 在新窗口打开，并定位当前文件光标。
- [ ] 文件侧边栏、快照侧边栏和底部面板可拖拽调整，刷新或重启后保持尺寸。
- [ ] 分隔线支持方向键调整和双击恢复默认，1024×720 下不挤压或遮挡面板内容。

## clangd

- [ ] 安装 LLVM 后重新检测并绑定带 `clangd` 的工具链。
- [ ] 打开 C++ 文件后状态栏显示“clangd 已连接”。
- [ ] 输入标识符可出现语义补全。
- [ ] 悬停显示类型/声明信息。
- [ ] F12 或 Monaco 定义操作可打开目标文件并定位。
- [ ] clangd 诊断进入问题面板和编辑器标记。
- [ ] 未安装 clangd 时仍可基础编辑，不反复弹错。

## GDB 调试

- [ ] 绑定带 GDB 的 GCC 工具链。
- [ ] 点击行号左侧槽位，出现红色断点。
- [ ] 点击“调试”，程序在断点暂停并高亮当前行。
- [ ] 调试面板显示局部变量和调用栈。
- [ ] “继续、跨过、进入、跳出、停止调试”可用。
- [ ] 未手动设置断点时，以当前光标行创建首个断点。
- [ ] 中文项目名称下断点仍可命中，位置显示为项目原文件。

## 安全与降级

- [ ] Renderer 不能访问 Node、Electron 或通用 IPC。
- [ ] 所有文件路径由 Main 通过项目 Root 和 `safePath()` 校验。
- [ ] 未绑定工具链、缺失 clangd/clang-tidy/GDB 时给出可执行提示。
- [ ] MSVC、LLDB 和多文件调试未被界面误报为已支持。

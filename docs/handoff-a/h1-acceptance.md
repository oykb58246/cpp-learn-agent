# H1 接收清单

## 环境与工程

- [ ] 在独立目录执行 `pnpm install`。
- [ ] 执行 `pnpm verify` 全部通过。
- [ ] 执行 `pnpm dev`，主窗口正常显示且无现场改代码需求。
- [ ] 执行 `pnpm package:dir`，目录包能够启动。

## 工作区与项目

- [ ] 原生目录选择器可以登记 Root。
- [ ] 新 Root 默认为只读检查，信任后才能写入。
- [ ] 手动建立单文件、多文件和 CMake 项目。
- [ ] 题目和描述模式能够预览确定性文件树。
- [ ] 导入已有项目不会改写原始文件。
- [ ] 项目可只移除登记，也可经原生确认后删除磁盘目录。

## 文件与快照

- [ ] 文件树、读取、创建、复制、移动、重命名、删除和搜索可用。
- [ ] 外部修改会刷新或触发 Dirty 冲突，不会静默覆盖。
- [ ] 保存前和删除前自动创建快照。
- [ ] 手动快照、恢复预览、恢复和删除可用。
- [ ] 路径穿越、设备名和 Root 外 Junction 均被拒绝。

## 数据和安全

- [ ] 重启后设置、工作区、项目和快照保持。
- [ ] 迁移失败时旧数据可读，写操作被拒绝。
- [ ] Renderer 无 Node、Electron 和通用 IPC 能力。
- [ ] Preload 方法与 `CppPetApi` 一致。

## 界面

- [ ] 首页和工作区浅色、深色均可用。
- [ ] 1440×900 与 1024×720 下无内容遮挡或横向溢出。
- [ ] 标题栏拖拽、Windows 原生窗口按钮和系统对话框可用。
- [ ] 空、加载、错误、权限拒绝和恢复状态均有反馈。

## B 接入

- [ ] 能用 `EditorHost` 替换基础文本编辑器而不改 FileService。
- [ ] 能通过 contracts 新增工具链类型和 IPC。
- [ ] 已阅读 `architecture.md`、`contracts.md`、`database.md`、`runbook.md` 和 `known-issues.md`。
